# Localization workflow
French is the canonical fallback. Core localeRows hold fr/en/de/zh-Hans; extraKeys and extraPacks define additional offline packs. Add a stable key and translation for each new UI message; avoid concatenating localized fragments. Keep user content, code, names, imported records and secrets out of automatic translation. For Academy, translate lessons, answers and explanations with identical IDs and answer indices. For Intel, publish original source links and reviewed localized summaries as separate fields. Do not mark a locale complete until inventory, plural rules, accessibility attributes, mobile layout, offline switching and RTL when applicable are verified. CI runs tests/localization.cjs; it does not certify completeness. Browser Translator is not a Safari-compatible fallback; evaluate local models separately with license, memory and download checks. No costs or external network calls in this release.
